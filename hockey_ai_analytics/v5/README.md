# Pilot 001F — V5: обнаружение фигур и сопровождение нескольких объектов

Это следующий эксперимент после V4. **Не релизная хоккейная аналитика.**
RED_TEST_01 не отождествлён с Матвеем.

## Повторить локально

Использовался Python 3.13.3 / macOS ARM64. Версии окружения — environment_freeze.txt.
Веса models/yolo11s.pt — официальные Ultralytics, SHA-256 сохранён в run_manifest.json.
Исходник ожидается в ../evidence/source.mov; прежний предварительный эталон —
../results/reference_ground_truth_PROVISIONAL.csv. Он не читается трекером.

```sh
python run_multitrack.py
python review_v5.py
python -m unittest discover -s . -p 'test_*.py' -v
python package_v5.py
```

package_v5.py требует visual_audit_record.json с хешами именно просмотренных
предсказаний и исходника. Если хеш изменился, необходимо повторить визуальную
проверку; автоматическое обновление записи аудита недопустимо. Результат
визуальной проверки ассистентом не равен независимой проверке человеком.

## Выходы

- results/v5_multi_target.mp4 — слева автоматические объекты с неподтверждёнными ID,
  справа V5 для выбранного игрока. Зелёного ручного эталона в видео нет.
- results/on_ice_tracks.csv — гипотезы фигур на льду, включая вратарей и судей.
- results/target_v5_raw.csv — неизменённые автоматические решения до аудита.
- results/target_identity_audit.csv — отдельный визуальный аудит цели.
- results/version_comparison.csv — V3/V4/V5 на одном предварительном эталоне.
- results/qa_summary.json — метрики и точные интервалы пропусков.
- results/scene_context.jsonl — взаимное расположение гипотез; шайба, владение,
  игровая фаза и тренерская оценка остаются неизвестными.
- results/geometric_observations.csv — только кандидат разворота по экрану,
  без утверждений о намерении, владении или тактическом качестве.
- review/ — все кадры цели на контактных листах и контрольные рендеры.

V5a сохранён отдельно: coverage 94,0%, но более слабая проверка перекрытий.
Финальная версия сознательно чаще отказывается и получает 89,9%.
Не выбирать вариант только по красивому числу покрытия.
