# V8 — инструменты сопровождения и распознавания

Исследовательский стенд. Новый код и результаты находятся отдельно от интерфейса V6. Пользовательские видео не отправлялись сторонним сервисам. Тестовые игроки NHL не связаны с Матвеем.

## Главный результат: сопровождение выбранного игрока

Тот же внешний фрагмент, 300 кадров, цель видна в эталоне на 187 кадрах. IoU ≥ 0.5. Настройка ансамбля выполнена до завершения SAM-прогона; отдельного нового матча для проверки ансамбля пока нет.

| Показатель | V7: фиксированный ID | SAM 2.1 | SAM + детектор + предохранитель |
|---|---:|---:|---:|
| Верные положения | 61 | 180 | 179 |
| Покрытие верными положениями видимой цели | 32.6% | 96.3% | 95.7% |
| Несовпадение рамки с эталоном | 0 | 7 | 2 |
| Метки при отсутствии цели в эталоне | 0 | 7 | 0 |
| Отказы на видимых кадрах | 126 | 0 | 6 |

Два остаточных несовпадения ансамбля — кадры 179 и 181, IoU 0.438 и 0.476. Визуальный просмотр ассистентом показывает рамки на том же белом игроке, но с отличающимися границами; явный перескок на соседнего человека не обнаружен на этих двух кадрах. Эталон не исправлялся, ошибки остаются в метрике. Это не независимая человеческая проверка и не доказательство отсутствия любых перескоков.

SAM 2.1 восстанавливает выбранного игрока после выхода; согласие с детектором, командой и временной стабильностью подавляет семь выводов при отсутствии цели по эталону. В основном интерфейсе V6 эта экспериментальная связка пока не включена. Воспроизводимые CSV, веса с хешем и сравнительное видео сохранены. Полная обработка SAM на CPU заняла около 190 секунд для 10 секунд видео; это офлайн-эксперимент, не заявленная работа в реальном времени.

Для дальнейшего принятия нужны другие матчи, одинаковая форма рядом, длительное скрытие, монтаж и плохое разрешение. Точность принадлежности команде унаследована от диагностического V7 и не независимо перепроверена. Шайба, калибровка площадки и тактические события этим результатом не валидированы.

## Что подключено и проверено

- **ByteTrack в Ultralytics:** замена механизма сопровождения при сохранении хоккейного детектора. Те же 300 кадров VIP-HTD, 848×477, IoU ≥ 0.5. Получены 14 ID switches и IDF1 69.1%, против 7 и 71.8% у V7 BoT-SORT. Оставляем BoT-SORT для общей сцены на основании этого ограниченного сравнения. Это не доказательство превосходства на всех матчах.
- **SAHI 0.12.8:** перекрывающиеся участки 384×384, перекрытие 20%, вход 848 пикселей по ширине, обработка 960, вместе с полным кадром, NMS IoU 0.5, уверенность 0.25. На тех же 40 диагностических изображениях шайба: 32/40 верных обнаружений, 49 предсказаний — recall 80%, precision 65.3%. Раньше 26/40 при 33 предсказаниях — recall 65%, precision 78.8%. Покрытие выросло, ложные срабатывания выросли с 7 до 17. Автоматическая замена не принята. Пересечение выборки с обучением неизвестно.
- **Исходное разрешение для игроков:** тот же BoT-SORT, вход и обработка 1280, вместо 848 и 960. IDF1 71.1%, 13 смен личности, precision 89.9%, recall 79.9%. Предпочтительного результата не получено. Это проверка другого режима детализации, не нового алгоритма.
- **SAM 2.1 Tiny:** отдельное сопровождение выбранной рамкой области с памятью между кадрами; реализация Ultralytics, входное видео 848×478, обработка 1024, CPU. Используется только первая эталонная рамка как имитация ручного выбора. Остальные эталонные рамки доступны только оценке. Нулевые рамки пустых масок означают отсутствие наблюдения. Единица уверенности в стандартной визуализации SAM не является вероятностью правильной личности.
- **Экспериментальная проверка согласия:** SAM должен совпасть с одним игроком хоккейного детектора (IoU ≥ 0.5), его команда должна совпасть с начальной, превосходство над вторым кандидатом по IoU ≥ 0.15; нужно три последовательных подтверждения одного ID детектора. После разрыва счётчик сбрасывается. Эти правила зафиксированы до завершения SAM-теста. Результат остаётся автоматической гипотезой, не ручным подтверждением личности.

## Кандидаты для следующих этапов — пока не подключены

| Инструмент | Для чего рассматриваем | Что ещё требуется доказать |
|---|---|---|
| SAM 3 | Выделение и сопровождение объектов по подсказкам | Выигрыш на хоккее относительно уже проверяемого SAM 2; стоимость обработки и доступность весов |
| CoTracker | Движение нескольких точек на форме и оценка согласованности движения | Точки не подтверждают человека после выхода; нужна проверка дрейфа при перекрытиях |
| PaddleOCR | Номер формы на читаемых кадрах как дополнительная улика | Точность на наклонённых, размытых спортивных номерах; согласование нескольких кадров и явный отказ |
| CVAT | Независимая ручная разметка видео, скрытий и личностей | Рабочая сессия разметчика и аудит спорных эпизодов; сам по себе качество модели не улучшает |
| FiftyOne | Сравнение моделей и группировка ошибок для дообучения | Организация независимых матчей и категорий ошибок; не заменяет эталон |

Не устанавливаем все платформы ради количества. Уже работающий стенд фиксирует источники, предсказания и метрики; CVAT/FiftyOne нужны при расширении разметки и обучения. Визуальное увеличение/генеративное улучшение качества не используется как доказательство номера или шайбы: восстановленные детали могут не соответствовать исходному видео.

## Архитектура

Общая сцена: хоккейный детектор → BoT-SORT → команда и тип объекта. Выбранный игрок: ручная рамка → SAM → согласие с общей сценой → гипотеза либо отказ. Шайба: отдельный режим детализации и будущая временная проверка; попадание точки в рамку игрока не означает владение. Площадка: отдельная калибровка, пока не выполнена. Игровые оценки остаются заблокированы там, где необходимые наблюдения отсутствуют.

## Воспроизведение

Используются зафиксированные входы V7 и окружение requirements_lock.txt. Запуск из корня проекта с Python этого окружения:

```sh
export YOLO_CONFIG_DIR="$PWD/hockey_ai_analytics/v7/runtime"
python hockey_ai_analytics/v8/benchmark_bytetrack.py hockey
python hockey_ai_analytics/v8/benchmark_high_detail.py hockey
python hockey_ai_analytics/v8/test_sahi.py
python hockey_ai_analytics/v8/test_sam2.py
python hockey_ai_analytics/v8/test_hybrid.py
python hockey_ai_analytics/v8/finalize.py
python -m unittest discover -s hockey_ai_analytics/v8/tests -v
```

SAM-веса автоматически получены из официального релиза Ultralytics: https://github.com/ultralytics/assets/releases/download/v8.4.0/sam2.1_t.pt. SHA-256 записывается в результат. Пять тестов предохранителя проверяют задержку подтверждения, неоднозначные дубликаты, другую команду, сброс после потери и смену ID. Пять тестов метрик V7 также пройдены. Соседние кадры зависимы, один фрагмент не является приёмкой для всех матчей. Числа времени обработки — журнал запуска, не строгий тест производительности.
