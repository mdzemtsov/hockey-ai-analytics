> Historical Notion snapshot. Design targets and older status claims are not current implementation guarantees. See [current baseline](../../BASELINE_QA.md). Child-identifying names, team name and individual profile details have been generalized for public sharing.

**Design rules only, not trained/validated AI decisions.** Each rule is inactive pending age-specific source review and coach validation. Four-level statuses: DRAFT → SOURCE\_REVIEWED → COACH\_APPROVED → PILOT\_VALIDATED. All rules currently DRAFT. For every episode separately record ID certainty, puck visibility, geometry certainty, role context and source timestamp. A missing crucial field means ABSTAIN, not low performance.

- Required visible evidence: visible number/color + parent reference.
- Exclusion/uncertainty: similar jerseys; occlusion.

- Guardrail: block publish if unresolved.

## Rule promotion gates

1. Link a primary-source paragraph/page or clearly mark inference. 2. Obtain two contrasting annotated real clips including an exception. 3. Youth coach checks applicability to game format and age. 4. Test abstention on occlusion. 5. Freeze rule version and record change log. No silent retroactive regrading.
