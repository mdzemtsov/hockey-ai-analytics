> Historical Notion snapshot. Design targets and older status claims are not current implementation guarantees. See [current baseline](../../BASELINE_QA.md). Child-identifying names, team name and individual profile details have been generalized for public sharing.

## User command

'Вперёд. Новое видео.' Optional override: game date, jersey number, uniform color, format and number of clips. If no override, use stored the selected player profile and newest unprocessed authorized file in incoming folder. Ask only when multiple equally recent files or player identification is ambiguous.

## What is not yet implemented

No working Drive watcher, cloud GPU video tracking service, persistent job scheduler or video renderer has been deployed. The Notion project is a specification and cannot execute code. ChatGPT Work might orchestrate multi-step work, but its exact media/GPU/large-file abilities must be verified. Do not promise end-to-end unattended processing until a real pilot passes.

## Workflow state machine

DISCOVERED → RIGHTS\_CHECK → INGESTED → MEDIA\_VALIDATED → TRACKING → CANDIDATE\_EVENTS → EVIDENCE\_REVIEW → COACHING\_REVIEW → SCRIPTED → RENDERED → QA\_PASSED → PUBLISHED. Terminal statuses: NEEDS\_USER\_CONFIRMATION, PARTIAL, FAILED, BLOCKED\_RIGHTS. Every state logs run ID, version, timestamps, error and retry count. Idempotent file-ID and checksum prevents duplicate runs.

## Data entities

- PlayerProfile: player\_id, birth\_year/age\_band, team, preferred role (non-binding), jerseys by season, parents' sharing consent, source policy.
- Game: game\_id, source IDs, format, game date, opponent optional, ruleset, team color, rink, camera, attacking directions, video timestamps, state.
- Track: track\_id, candidate identity, jersey OCR votes, temporal span, confidence, manual-confirmation status.
- Event: event\_id, source in/out, decision timestamp, phase, observations, uncertainty, alternatives, rule references, execution/outcome, review flags.
- Artifact: game\_id, MP4 path, captions, JSON manifest, PDF/Notion report optional, model version, renderer version, reviewer, privacy permissions.

## Default report package

- Full original source unchanged.
- Ten selected episodes (or fewer when insufficient reliable evidence); each includes original lead-in, pause, highlighted player, evidence-based tactical alternative, slow replay and 20–40 seconds of Russian commentary.
- Parent video target 6–10 minutes, optional child video 2–4 minutes; durations are goals, not fixed constraints.
- Episode index with timestamps and clickable links where platform supports; written summary with no more than 3 practice priorities and longitudinal comparison only with valid comparable footage.

## Release criteria

- Source rights/consent recorded.
- the selected player identity verified for every narrated event; manual approval where uncertain.
- All puck claims backed by visible frames; all arrows geometrically anchored or explicitly illustrative.
- Expert-reviewed tactical rubric; no invented causal certainty.
- MP4 audio/video integrity and playable output confirmed.
- Restricted Drive sharing, no public sharing by default.

## Pilot milestones

M0 documentation and source audit; M1 ingest one 5–10 min GoPro; M2 reliable player identification; M3 annotate 3 vetted episodes; M4 produce 10-episode parent video; M5 full-match; M6 cross-game trend; M7 chat-triggered reliable orchestration. Each milestone has explicit pass/fail evidence.

## Security and economics

- Child footage is sensitive personal material; minimize personal data, encrypt storage where supported, apply least privilege and retention policy, no external training use without explicit informed consent.
- Respect LiveBarn platform terms and venue recording rights; do not bypass DRM or access restrictions.
- Estimate costs only after measuring minutes of footage, FPS, GPU inference rate, VLM frame sampling, storage and narration; no unverified flat price claims.
- Track hallucinations, privacy breaches and child-facing negative feedback as critical failure classes.
