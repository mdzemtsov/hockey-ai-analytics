# 🗺️ 08 — Roadmap and pilot acceptance criteria

[Notion source](https://app.notion.com/p/3fec8554a5d68140a6b9f5a9f8680108?pvs=204) · [Index](../README.md)

> Historical Notion snapshot. Design targets and older status claims are not current implementation guarantees. See [current baseline](../../BASELINE_QA.md).

## Phase 1 — Coaching knowledge base

Verify 20 distinct authored hockey books, not annual editions counted as independent theories; document full-text access, edition, ISBN, page references where lawful. Crosswalk official USA Hockey 8U/10U and Hockey Canada U9/U11 development principles with 30 existing decision cards. Deliver a source-linked rules registry and explicit age applicability.

**Acceptance:** each active rule has evidence source, observation criteria, alternative action, exception, child-friendly wording, and review status.

## Phase 2 — Video recognition pilot

Obtain authorized 5–10 minute GoPro or LiveBarn video and player's jersey number, color and on-ice reference frame. Label a ground-truth sample manually; evaluate player ID, track continuity, puck visibility, event boundaries and timestamps. Do not presume ChatGPT Work has GPU or long-video processing capacity.

**Acceptance:** track error and uncertain segments measured; only identity-confirmed events proceed.

## Phase 3 — Hockey evaluation

Select 10 visible candidate episodes; separately score decision, execution and outcome; require source timecodes and two plausible options. Independent Claude critique and ideally youth-coach review.

**Acceptance:** all narrated claims grounded in footage; disagreements documented; no invented puck or gaze evidence.

## Phase 4 — Annotated video pilot

Render 3 vetted clips first, then a 10-episode MP4 with player highlights, pauses, alternatives, subtitles and Russian narration. Parent and child versions optional.

**Acceptance:** playable video, correct person marked, arrows aligned, clear audio and restricted sharing.

## Phase 5 — Chat-triggered workflow

Input Drive folder + saved profile + 'Вперёд. Новое видео'; launch authorized process, handle retries/ambiguous player IDs, save outputs to Drive, record run status and QA in Notion.

**Acceptance:** end-to-end repeatability on at least three different games without manual file manipulation by user; no unsupported claim of automation until tested.

## Immediate decisions needed

First test footage (5–10 min, preferably stable GoPro); jersey number and uniform color; preferred parent vs child review; rights/consent. These are not blockers for completing research.

## Risk register

R1 wrong child identity — critical; R2 invisible puck and occlusions — high; R3 age-inappropriate tactical recommendation — high; R4 backend/runtime unavailable — critical; R5 rights/privacy breach — critical; R6 overclaiming full-book analysis — high. All require mitigation before unattended release.
