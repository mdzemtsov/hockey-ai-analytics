# Partner demo and acceptance notes

Use an authorized 5–15 second clip with two visibly different teams. Keep a notebook of exact failure times.

1. Select a language, upload the clip, choose the interval, and run team review.
2. Check every displayed box against the original frame. Separate missed players, wrong object classes, mixed-person boxes and wrong jersey colors.
3. Play with pauses. Verify that the overlay matches the paused moment; listen in both languages and use Stop/Continue.
4. Check any puck candidate against the visible puck. Do not assume it is correct because it is labeled.
5. In player mode, capture a clear frame and select one player. Confirm the frame is anchored and that other unverified identities remain UNKNOWN.
6. Try the separate tracking page. Deliberate overlap/loss should require manual reconfirmation; earlier gaps must stay empty.
7. Download the reports and record input hash, app version, interval and unresolved observations.

Passing this checklist establishes usability only. A recognition benchmark needs independently checked labels and fixed evaluation examples. A coaching benchmark additionally needs a qualified hockey reviewer and context sufficient to judge decisions.

Record bugs with expected/observed behavior, version and safe reproduction steps. Do not attach child/player footage to GitHub issues by default; keep it in separately authorized storage.
